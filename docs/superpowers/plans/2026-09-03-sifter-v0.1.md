# SIFTER v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a local-first Python package and Streamlit application that fits and compares Gaussian, Lorentzian, and Voigt decompositions of one-dimensional spectra, with conservative Fourier assistance, diagnostics, uncertainty, and synthetic-only public validation.

**Architecture:** A typed scientific core accepts an immutable `Spectrum`, creates deterministic candidate `ModelSpec` values from real-space and optional Fourier diagnostics, fits each candidate against the original observations, and returns a versioned `FitResult`. File loaders, plotting/export code, and Streamlit are adapters around that core; they contain no fitting logic.

**Tech Stack:** Python 3.11-3.13, NumPy, SciPy, pandas, Plotly, Streamlit, pytest, pytest-cov, Ruff, mypy, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-03-sifter-v0.1-design.md`

## Global Constraints

- Fourier-domain evidence initializes and diagnoses fits; only original-domain observations determine parameters and scores.
- Public tests, examples, screenshots, and benchmarks use deterministic synthetic spectra only.
- Root `data/`, `private/`, `results/`, `outputs/`, `reports/`, and `benchmark_results/` remain ignored and must never enter Git history.
- Peak amplitude means integrated area; Gaussian width is `sigma`, Lorentzian width is HWHM `gamma`, and Voigt exposes both.
- Automatic candidates use one shared peak family per model and at most six peaks by default.
- BIC selects the recommendation; AICc is also reported; delta BIC is never presented as a probability.
- Ordinary FFT diagnostics fail closed on materially nonuniform grids unless the caller explicitly opts into diagnostic-only interpolation.
- Reduced chi-squared is reported only when positive measurement standard deviations are supplied.
- `FitResult.schema_version` is exactly `sifter.fit_result.v1`.
- The supported Python range is 3.11 through 3.13 and the license is BSD-3-Clause.
- No source file may send telemetry or spectrum content over a network.

```python
def gaussian(x: ArrayLike, *, area: float, center: float, sigma: float) -> NDArray[np.float64]:
    values = np.asarray(x, dtype=np.float64)
    _validate(area, sigma)
    z = (values - center) / sigma
    return area * np.exp(-0.5 * z * z) / (sigma * np.sqrt(2.0 * np.pi))


def lorentzian(x: ArrayLike, *, area: float, center: float, gamma: float) -> NDArray[np.float64]:
    values = np.asarray(x, dtype=np.float64)
    _validate(area, gamma)
    return area * gamma / (np.pi * ((values - center) ** 2 + gamma**2))


def voigt(
    x: ArrayLike, *, area: float, center: float, sigma: float, gamma: float
) -> NDArray[np.float64]:
    values = np.asarray(x, dtype=np.float64)
    _validate(area, sigma, gamma)
    z = ((values - center) + 1j * gamma) / (sigma * np.sqrt(2.0))
    return area * np.real(wofz(z)) / (sigma * np.sqrt(2.0 * np.pi))
```

Use exact Gaussian `2*sqrt(2*log(2))*sigma`, exact Lorentzian `2*gamma`, and the documented Olivero-Longbothum Voigt approximation `0.5346*(2*gamma) + sqrt(0.2166*(2*gamma)^2 + (2*sqrt(2*log(2))*sigma)^2)`.

```python
@dataclass(frozen=True, slots=True)
class ScaledPolynomial:
    coefficients: tuple[float, ...]
    x_offset: float
    x_scale: float

    def evaluate(self, x: ArrayLike) -> NDArray[np.float64]:
        z = (np.asarray(x, dtype=np.float64) - self.x_offset) / self.x_scale
        return np.polynomial.polynomial.polyval(z, self.coefficients)
```

```python
@dataclass(frozen=True, slots=True)
class InformationCriteria:
    aic: float
    aicc: float | None
    bic: float


def unweighted_information_criteria(*, n: int, p: int, rss: float) -> InformationCriteria:
    effective_rss = max(rss, np.finfo(float).tiny)
    aic = n * np.log(effective_rss / n) + 2 * p
    correction = None if n <= p + 1 else (2 * p * (p + 1)) / (n - p - 1)
    return InformationCriteria(aic, None if correction is None else aic + correction, n * np.log(effective_rss / n) + p * np.log(n))

    residual_variance: float | None
    reduced_chi_squared: float | None
    warnings: tuple[str, ...]
    failure_code: str | None
```
